Case · reference architecture Estudo de caso · arquitetura de referência

An end-to-end view of data infrastructure for credit funds.

Uma visão end-to-end da infraestrutura de dados em fundos de crédito.

A reference stack for a credit-fund data operation: raw data pulled via Selenium and public APIs, orchestrated by Apache Airflow, landed in a Postgres warehouse, and surfaced through internal dashboards and automated reports.

Uma stack de referência para a operação de dados de um fundo de crédito: dados brutos baixados via Selenium e APIs públicas, orquestrados pelo Apache Airflow, persistidos num warehouse Postgres e expostos via dashboards internos e relatórios automáticos.

On top of that sit the domain layers: a Python pricing library for Brazilian fixed income (ANBIMA conventions, B3 business calendar), and a credit-risk engine with SHAP explanations the investment committee can actually read.

Sobre essa base, as camadas de domínio: uma biblioteca Python de precificação de renda fixa brasileira (convenções ANBIMA, calendário de dias úteis B3) e um motor de risco de crédito com explicações SHAP que o comitê de investimentos efetivamente lê.
