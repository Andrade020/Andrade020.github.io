Case · reference architecture Estudo de caso · arquitetura de referência

An end-to-end view of data infrastructure for credit funds.

Uma visão end-to-end da infraestrutura de dados em fundos de crédito.

A reference stack for a credit-fund data operation: raw data pulled via Selenium and public APIs, orchestrated by Apache Airflow, landed in a file-based data lake tracked by JSON manifests, and surfaced through internal dashboards and automated reports.

Uma stack de referência para a operação de dados de um fundo de crédito: dados brutos baixados via Selenium e APIs públicas, orquestrados pelo Apache Airflow, persistidos num data lake baseado em arquivos e rastreado por manifests JSON, e expostos via dashboards internos e relatórios automáticos.

On top of that sit the domain layers: a table-driven cash-flow and liquidity engine for the fund's receivables, and an offline credit-risk scoring pipeline with SHAP explanations the investment committee can actually read.

Sobre essa base, as camadas de domínio: um motor de fluxo de caixa e liquidez orientado a dados para os recebíveis do fundo, e um pipeline offline de score de risco de crédito com explicações SHAP que o comitê de investimentos efetivamente lê.
