Context Contexto

The fund and what its data layer has to do.

O fundo e o que sua camada de dados precisa fazer.

Porto Real Asset is a credit-focused asset manager based in Rio de Janeiro. Its operation rests on receivables and structured credit (FIDCs), which means the data layer has to handle three very different shapes of input on the same daily clock: machine-readable feeds, a portal with no public API, and human spreadsheets.

A Porto Real Asset é uma gestora focada em crédito sediada no Rio de Janeiro. A operação repousa sobre recebíveis e crédito estruturado (FIDCs), o que significa que a camada de dados precisa lidar com três tipos muito diferentes de entrada no mesmo relógio diário: feeds machine-readable, um portal sem API pública e planilhas humanas.

Outputs serve three audiences. Investment analysts need positions, exposures, and macro context. Risk needs default probabilities with explanations. Operations needs reconciliation and audit trails.

As saídas atendem três públicos. Os analistas de investimento precisam de posições, exposições e contexto macro. Risco precisa de probabilidades de default com explicações. Operações precisa de conciliação e rastreabilidade.

01.

Pipeline orchestration & ingestion

Orquestração & ingestão

Apache Airflow · Selenium · REST/GraphQL · Python

~35 Airflow DAGs, tagged by role — download, consolidation, report, audit — with a sensor-style DAG polling state every five minutes and triggering what's ready. Three kinds of source: an RPA bot with a proper Page Object Model for the administrator's portal, REST/GraphQL clients for custodian APIs, and a standalone loader package for public macro data.

~35 DAGs do Airflow, tagueadas por papel — download, consolidação, relatório, auditoria — com uma DAG estilo sensor consultando o estado a cada cinco minutos e disparando o que estiver pronto. Três tipos de fonte: um bot de RPA com Page Object Model de verdade para o portal da administradora, clientes REST/GraphQL para APIs custodiais, e um pacote de loaders standalone para dados macro públicos.

  • Custodian REST/GraphQL endpoints for positions and cash statements.
  • Endpoints REST/GraphQL custodiais de posições e demonstrativos de caixa.
  • Public macro feeds (BCB, IBGE, CVM, CAGED, Tesouro) for context.
  • Feeds macro públicos (BCB, IBGE, CVM, CAGED, Tesouro) para contexto.
  • Selenium RPA with a Page Object Model where no API exists.
  • RPA com Selenium e Page Object Model onde não existe API.

02.

Data layer & idempotency

Camada de dados & idempotência

pandas · JSON manifests · parquet

No database behind this pipeline — a three-tier file lake instead (raw → reference/manual → consolidated), with idempotency and backfill driven by a JSON manifest per pipeline rather than database transactions. Every intermediate state is a file a human can open and diff.

Sem banco de dados por trás deste pipeline — um lake de arquivos em três camadas (raw → referência/manual → consolidado), com idempotência e backfill conduzidos por um manifest JSON por pipeline, não por transações de banco. Todo estado intermediário é um arquivo que um humano pode abrir e comparar.

Caught, via a sanity check born from a real incident: an administrator migration where BR/US number-format ambiguity inflated figures roughly 100×.

Pego por uma checagem de sanidade nascida de um incidente real: uma migração de administradora em que a ambiguidade de formato de número BR/US inflou valores em cerca de 100×.

03.

Cash flow & liquidity engine

Motor de fluxo de caixa & liquidez

scipy · numpy-financial · pandas

Table-driven amortization: each receivable's settlement rule lives in a spreadsheet, not in code, so a new asset type is an edit an analyst can make. IRR by numerical root-finding over the projected schedule, a senior/subordinated waterfall, and an audit DAG that flags assets with no matching rule before the 10am liquidity report.

Amortização orientada a dados: a regra de liquidação de cada recebível vive numa planilha, não no código, então um tipo de ativo novo é uma edição que um analista consegue fazer. TIR por busca numérica de raiz sobre o cronograma projetado, uma cascata sênior/subordinada, e uma DAG de auditoria que sinaliza ativos sem regra correspondente antes do relatório de liquidez das 10h.

04.

Quality gates & compliance

Gates de qualidade & enquadramento

pandas · hand-written parser · Airflow

No unit test suite — correctness is enforced at runtime instead: six named consistency checks on every load, a version-diff audit that catches silent restatements, and a compliance engine with a hand-written recursive-descent rule parser (no eval()) whose history is append-only by design.

Sem suíte de testes unitários — a correção é garantida em tempo de execução: seis checagens de consistência nomeadas em toda carga, uma auditoria de version-diff que pega reapresentações silenciosas, e um motor de enquadramento com um parser de regras recursivo-descendente escrito à mão (sem eval()) cujo histórico é append-only por desenho.

05.

Credit-risk scoring

Score de risco de crédito

scikit-learn · XGBoost · SHAP · Optuna

The output is not just a score: SHAP feature attributions ship with every prediction, ranked and signed, so a credit committee can read why and challenge it. Honestly offline and exploratory — reviewed by a person, not wired into a daily DAG, because that would need drift monitoring this platform doesn't have yet.

A saída não é só um score: atribuições SHAP saem com cada predição, ranqueadas e com sinal, para que um comitê de crédito leia o porquê e questione. Honestamente offline e exploratório — revisado por uma pessoa, não conectado a uma DAG diária, porque isso exigiria monitoramento de drift que esta plataforma ainda não tem.

06.

Reports & delivery

Relatórios & entrega

Flask · Jinja2 · Microsoft Graph · matplotlib

Six report generators (aging, concentration, liquidity, receivables flow, payment performance, compliance) render as self-contained HTML — pandas tables, matplotlib charts inlined as base64. A four-dependency Flask dashboard serves them on demand; a mailbox-driven watcher pushes the daily ones out automatically, before market open.

Seis geradores de relatório (aging, concentração, liquidez, fluxo de recebíveis, performance de pagamento, enquadramento) renderizam como HTML autocontido — tabelas pandas, gráficos matplotlib embutidos como base64. Um dashboard Flask de quatro dependências serve sob demanda; um watcher de caixa de e-mail dispara os diários automaticamente, antes da abertura do mercado.

Principles I work by

Princípios pelos quais trabalho

Reproducible by default

Reproduzível por padrão

Every output should be re-creatable from its inputs. Idempotent tasks, persisted intermediate state, audit trails as a feature.

Toda saída deve poder ser recriada a partir das entradas. Tasks idempotentes, estado intermediário persistido, rastreabilidade como recurso.

Explainable, not just accurate

Explicável, não só acurado

An investment committee does not consume probabilities, it consumes arguments. SHAP, feature attributions, and clear English (or Portuguese) matter as much as AUC.

Um comitê de investimentos não consome probabilidades, consome argumentos. SHAP, atribuições e português claro importam tanto quanto AUC.

Open stack, no vendor lock-in

Stack aberta, sem vendor lock-in

Python, Airflow, a file-based lake. The infrastructure should belong to the firm, not to a SaaS contract.

Python, Airflow, um lake baseado em arquivos. A infraestrutura deve pertencer à firma, não a um contrato SaaS.

Gates over test suites

Gates em vez de suíte de testes

No pytest suite here. What catches bad data is runtime checks against the live pipeline — consistency checks, version-diff audits, sanity checks against known totals.

Sem suíte pytest aqui. O que pega dado ruim são checagens em tempo de execução contra o pipeline ao vivo — checagens de consistência, auditorias de version-diff, checagens de sanidade contra totais conhecidos.

Quiet operations

Operações silenciosas

If the pipeline only wakes me up when something is genuinely wrong, it has been well designed.

Se o pipeline só me acorda quando há algo realmente errado, ele foi bem desenhado.

Documentation as code

Documentação como código

READMEs in every module, ADRs for non-trivial decisions, Mermaid diagrams over Confluence pages.

READMEs em cada módulo, ADRs para decisões não-triviais, diagramas Mermaid em vez de páginas no Confluence.
