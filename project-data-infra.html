Data Infrastructure for a Credit Asset Manager

Production
Porto Real Asset · Feb 2025 – Present Proprietary — architecture described publicly

Designed and built the complete data infrastructure for a credit fund manager — from the first git commit to daily production pipelines delivering risk reports to the investment team. I joined as the first (and only) data professional: every system described here was built by me from scratch.

Data sources integrated

Two production DAGs handle ingestion: porto_auto (custodian data) and dag_macro_data_downloader (public macro sources) — 13 sources in total.

  • Vórtx Custodian API · CARTEIRA — daily fund portfolio positions, asset master data, and FIDC quota balances
  • Vórtx Custodian API · DOCS — credit document registry and CCB metadata
  • Vórtx Custodian API · DEMONSTRATIVO_CAIXA — daily cash flow statements per sub-fund
  • Vórtx Custodian API · EXTRATO_BANCARIO — bank account transaction history
  • CVM — regulatory filings and FIDC registrations via open data portal
  • BCB / BACEN — SELIC target rate, DI projections, FX rates, and macro series
  • IBGE — inflation indices (IPCA, INPC) and national accounts data
  • Tesouro Direto — government bond reference prices and yield curves
  • CAGED — formal employment data for macroeconomic context
  • TSE — public electoral and political data
  • INMET — historical climate and weather data
  • B3 — DI futures curve data, reference rates, and benchmark prices for fixed income pricing
  • CCB PDF Documents — 5,000+ Bank Credit Notes extracted automatically by the PDF pipeline

Pipeline architecture

All pipelines are orchestrated by Apache Airflow running in Docker. DAGs are versioned in Git alongside the rest of the codebase. Each pipeline runs on a daily schedule and is idempotent — safe to re-run on failure. An intelligent backfill system detects missing business days and automatically recovers data gaps without duplicating records, handling weekends, Brazilian holidays, and API outages gracefully.

Data Sources → Airflow DAGs → Structured Storage → Risk Dashboard ↓ PDF Extraction Pipeline ↓ ML Credit Risk Models ↓ Automated Email Reports (Krvo)

What the system delivers daily

  • Consolidated FIDC portfolio position with pricing and risk metrics
  • Aging report: time-bucketed delinquency analysis per debtor and asset class
  • Cash flow projection for the fund's receivables portfolio
  • Credit risk scoring with SHAP-based explanations for each debtor
  • B3 benchmark rates and curve interpolation for fixed income pricing
  • Automated report emails to investment team via Krvo

Internal dashboard

A Flask + Jinja2 internal web application consumed by the investment team and portfolio managers. Three dedicated views cover the fund's operational needs: Posição de Ativos (live portfolio positions with pricing and risk metrics), Cotas (daily NAV and fund quota tracking), and Adm Mudanças (administrative change log for positions, classifications, and renegotiations) — replacing manual Excel workflows entirely.
