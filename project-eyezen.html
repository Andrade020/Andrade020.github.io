EyeZen · screen filter for the long sessions.

A Windows application that applies a color filter over your screen to reduce eye strain during long reading and coding sessions. Lives in the system tray, answers to global shortcuts, and remembers your last setting.

Download EyeZen.exe ↗ GitHub ↗

A ground-up rewrite in Rust, v2, is out — smaller, tray-first, 24 filters — see EyeZen v2 →

What it is

Four filter intensities. One shortcut away.

EyeZen overlays a warm-toned, opacity-adjustable filter on top of your entire display. It runs completely out of the way — no window, no toolbar icon in focus, just a system tray entry. You switch filter levels with global keyboard shortcuts without leaving whatever you're doing.

Useful during late-night reading sessions, extended document review, and any situation where reducing blue-light exposure matters more than color accuracy.

What EyeZen does

  • Applies a warm color filter over the entire screen to reduce blue-light exposure
  • Four intensity levels switchable with Ctrl+Alt+1 through Ctrl+Alt+4 — global shortcuts, always available
  • System tray operation — no open window, no interface in the way
  • Persistent state: last selected level is restored on launch
  • Distributed as a standalone .exe — no Python installation required
  • Compatible with Windows 10 and Windows 11

Download & setup

Download & configuração

1. Download

1. Baixar

Go to the GitHub Releases page and download the latest EyeZen.exe. No Python, no installer — just a standalone executable. Windows 10 or 11 required.

Acesse a página de Releases no GitHub e baixe o último EyeZen.exe. Sem Python, sem instalador — executável standalone. Requer Windows 10 ou 11.

2. Run

2. Rodar

Double-click the .exe. EyeZen starts silently and appears in the system tray (bottom-right corner). No window opens — it stays out of your way.

Dê dois cliques no .exe. O EyeZen inicia silenciosamente e aparece na bandeja do sistema (canto inferior direito). Nenhuma janela abre — fica fora do caminho.

3. Use

3. Usar

Press Ctrl+Alt+1 through Ctrl+Alt+4 to cycle through filter intensities, from off to maximum warmth. Right-click the tray icon to exit. The last selected level is restored automatically on next launch.

Pressione Ctrl+Alt+1 a Ctrl+Alt+4 para mudar a intensidade do filtro, do desligado ao máximo. Clique com o botão direito no ícone da bandeja para sair. O último nível selecionado é restaurado automaticamente na próxima execução.
