Krvo

Open Source
Python · Microsoft Graph API · Azure AD · PyInstaller Personal Project · 2024

Krvo (from the Old Slavic word for "raven") is a digital messenger: a tool for automated email sending via Microsoft Graph API. Like a raven carrying messages, it delivers your files reliably and consistently — including from Airflow pipelines that can't authenticate interactively.

View on GitHub ↗

What it does

  • Sends files by email via Microsoft Graph API (ROPC authentication — works from scripts)
  • Rule-based routing: configure which directory maps to which recipient list and email template
  • Recipient list management — organize contacts into named groups
  • Rate limiting — prevents accidental spam with configurable cooldown periods
  • Customizable templates for subject and body, with {filename}, {date}, {datetime} variables
  • Full GUI for configuration; full CLI for automation and integration with other systems
  • Compiled to a standalone .exe via PyInstaller — no Python required to run
  • Credentials stored in %APPDATA%/Krvo/ (Windows) or ~/.config/Krvo/ (Linux)

Why I built it

At Porto Real Asset, Airflow pipelines generate daily risk reports that need to be emailed to the investment team. The standard approach (SMTP with username/password) doesn't work for organizational Microsoft accounts with MFA or Conditional Access policies. Krvo uses ROPC flow against Azure AD, which allows non-interactive authentication from pipeline scripts while respecting organizational security policies.

The rule-based routing means I configure once and forget: "any file matching pattern X goes to list Y with template Z" — no code changes to add a new report type.

CLI usage

python krvo.py send relatorio.pdf python krvo.py send --folder ./relatorios python krvo.py send --dry-run arquivo.pdf # simulate without sending python krvo.py status --json # machine-readable status python krvo.py auth test # verify Azure credentials

Integration from Python

import subprocess, json result = subprocess.run( ["python", "krvo.py", "send", "--json", "report.pdf"], capture_output=True, text=True ) data = json.loads(result.stdout) if data["success"]: print(f"Sent to {data['recipients_count']} recipients")
