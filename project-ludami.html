ludami · curate links, share spaces.

A link curation platform for shared spaces. Save YouTube videos and URLs into thematic collections, annotate each one, and share with collaborators. No spreadsheet, no chat thread, no chaos.

GitHub ↗

What it is

A shared space for the links that matter.

Bookmarks are personal. ludami is for the links that belong to a group — a study cohort, a project team, a reading club. You create thematic collections, add links with your own annotations, and share the space with whoever needs access.

The focus is on YouTube videos and URLs in general, organized around a simple but expressive taxonomy: collection → link → annotation. Nothing more complex than needed.

Built as a Progressive Web App, ludami is installable on desktop and mobile straight from the browser — no app store, no native build.

What ludami does

  • Create and name thematic collections to organize any set of links around a topic
  • Save YouTube videos and arbitrary URLs with custom titles and personal annotations
  • Share collections with other users for collaborative curation — same space, multiple contributors
  • Install as a Progressive Web App on desktop or mobile — no app store, no native build required
  • Clean, minimal interface: no algorithmic feeds, no distractions, just the links you chose
